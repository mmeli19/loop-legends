# Loop Legends

Interactive computer science practice apps built by Esther Burnett.

- **student/** – Loop Legends for Students: a Computer Science I learning app for high school students with lessons, practice questions, games, and progress tracking. Code examples switch between Python and Java.
- **teacher/** – Loop Legends for Teachers: TExES Computer Science 8-12 (241) exam prep for teachers, organized by exam domain.

Each app is a single self-contained `index.html` file. Open it in any web browser to run it.

Status: prototype (not yet published to app stores).
